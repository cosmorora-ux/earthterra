# PvP 전투 관리 프로그램 (v2)

운영진 전용 3:3 PvP 전투 계산기입니다. Tkinter 기반 GUI, Python 표준 라이브러리만 사용하므로
별도 설치 없이 Python(+Tkinter)만 있으면 바로 실행됩니다.

## 폴더 구조

```
battle_manager/
├── config.py        # 전투 수식·상수 (GUI의 "⚙ 전투 수식 설정"에서도 수정 가능)
├── models.py         # Character, Skill(공격/방어/공격유도/회피/힐/시간초과/도주) 클래스
├── database.py       # 캐릭터 데이터베이스 (붙여넣기 파싱 + characters.json 자동 저장/로드)
├── battle.py          # Battle, GameManager 클래스 (턴/라운드/되돌리기/자동 선공 결정)
├── gui.py             # Tkinter 다크모드 GUI
├── main.py            # 실행 진입점
├── characters.json    # 캐릭터 데이터베이스 (최초 실행 시 자동 생성)
└── formulas.json      # 운영자가 GUI에서 수정한 전투 수식 (수정 시에만 생성)
```

## 실행 방법

```bash
python main.py
```

Python 3.9 이상 권장. Tkinter가 없다면(Linux) `sudo apt install python3-tk` 로 설치하세요.

## 최신 패치 (공격유도 - 아군 타겟 시 방어 크레딧 누락 버그 수정)

보내주신 실제 전투 로그로 원인을 정확히 찾았습니다. 어떤 탱커(E)가 본인에게 공격유도를 걸어
어그로 1 + 방어 크레딧 1을 얻은 상태에서, **다른 탱커(B)가 그 탱커(E)를 대상으로 공격유도를
한 번 더 걸면** 어그로는 2로 정상 누적되는데, 방어 크레딧은 "본인을 타겟할 때만" 붙는 조건이
남아있어서 1개밖에 붙지 않았습니다. 그 결과 첫 번째 강제 공격은 능동 방어, 두 번째는 방어
크레딧이 바닥나 무방비로 새는 문제가 있었습니다.

- **수정** : 공격유도를 사용하면 대상이 본인이든 아군이든 상관없이 항상 "어그로 1회 + 능동
  방어 크레딧 1회"가 함께, 그리고 그 대상에게 부여됩니다. 여러 명이 같은 대상에게 걸어도
  어그로 횟수와 방어 크레딧 개수가 항상 정확히 같이 움직입니다.
- 실제 로그의 정확한 상황(E 자가 공격유도 → B가 E를 대상으로 공격유도 → 적 딜러 2명이 순서대로
  공격)을 그대로 재현해서, 이제 두 공격 모두 능동 방어로 정산되는 것을 확인했습니다.

## 이전 패치 6 (어그로·능동방어 완전 분리 - 추가 버그 수정)

지난 패치에서 "어그로가 라운드를 넘기면 방어가 사라지는" 문제를 고치면서, 어그로 횟수에 맞춰
방어 계층을 다시 채워 넣는 방식을 썼는데, 이 방식이 **"이미 다른 공격으로 방어가 먼저
소모된 경우"까지 다시 채워버려서 능동 방어가 중복 발동하는 새 버그**를 만들었습니다.
(예: 대기 중이던 공격이 공격유도 사용 시점에 능동 방어로 정산됐는데, 다음 라운드에 아직
남은 어그로 횟수만큼 방어가 또 채워져서 실제로는 2번째 능동 방어가 공짜로 생기던 문제)

- **능동 방어와 어그로를 완전히 독립적인 자원으로 분리**했습니다. 공격유도(본인)를 한 번
  사용하면 "능동 방어 1회분"과 "어그로(강제 공격) 1회분"이 각각 생기며, 이 둘은 서로
  동기화되거나 다시 채워지지 않고 각자 실제로 소모될 때(공격을 받았을 때 / 강제 공격이
  실행됐을 때)만 개별적으로 사라집니다.
- 능동 방어 1회분은 라운드 경계와 무관하게 그 자체로 유지되다가, **어떤 공격이든(강제 공격이
  아니어도) 가장 먼저 자신에게 오는 피격에 소모**됩니다.
- 어그로 횟수는 기존과 동일하게, 강제된 팀의 실제 공격 선언 시에만 소모되며, 그 공격이
  능동 방어를 받는지 무방비로 맞는지는 방어 자원의 잔여량에 따로 달려 있습니다.
- 캐릭터 이름 옆 🛡 뱃지는 이제 "라운드 한정 방어"와 "어그로 유래 방어 크레딧"을 합산해서
  보여줍니다.

## 이전 패치 5 (힐 예외 범위 정정 + 어그로/방어 버그 수정 + 로그 UI 개선)

15. **[정정] 힐러 자유 행동 범위** — "힐러는 상대 턴이어도 행동 가능"이 아니라 **"힐만"** 미룰 수
    있는 것으로 수정했습니다. 힐러라도 공격/본인방어/시간초과/도주는 반드시 자기 팀 턴에만
    사용할 수 있고, 자기 팀 턴이 아닐 때는 "힐" 버튼만 활성화됩니다.
16. **[버그 수정] 라운드를 넘긴 어그로의 방어 소실** — 공격유도(본인)로 부여된 능동 방어 계층이
    매 라운드 시작 시 초기화되어, 어그로가 라운드를 넘겨 누적된 경우(예: 2회) 실제로는 방어가
    1번만 걸려있고 두 번째 피격은 무방비로 처리되는 문제가 있었습니다. 이제 남아있는 어그로
    횟수만큼 방어 계층도 함께 유지되어, 소모되지 않은 어그로에는 항상 능동 방어가 붙어있습니다.
17. **로그 패널 개편** — 러너 공유 로그를 위, 운영진 로그를 아래로 배치했습니다. 운영진 로그는
    제목 옆 **▼/▶ 버튼**으로 접었다 펼 수 있습니다.
18. **방어 행동 강조** — 공격(⚔ 빨강)·힐(✚ 초록)처럼, **방어 관련 행동에도 아이콘과 색이
    추가**되었습니다. 본인방어/방어 선언은 🛡 파란색으로, 공격유도는 🎯 주황색으로 표시되며,
    러너 공유 로그의 "방어 값" 표시도 함께 강조됩니다.

    구분이 쉬워집니다.

## 이전 패치 3 (재굴림/HP/크리티컬 공식 정정 + 어그로 지속 시스템)

1. **[버그 수정] 재굴림 로직** — 재굴림 기준치 이하가 나왔을 때 무조건 새 값으로 교체하던 것을,
   "원래 값과 재굴림한 값 중 더 높은 값"을 채택하도록 수정했습니다.
2. *(방어 계수는 이전 패치에서 15로 상향 완료)*
4. **HP 공식 변경** — 체력 구간 표 대신 선형 공식으로 변경했습니다.
   `최대 HP = 150 + 체력 × 15` (체력 0 = 150, 체력 5 = 225)
5. **[버그 수정] 크리티컬 공식 재정정** — 확률/배율에 관여하는 스탯이 뒤바뀌어 있던 것을 바로잡았습니다.
   - 크리티컬 **확률** = 기본값 + **행운**(주 요인) + **정신**(부 요인)
   - 크리티컬 **배율** = 기본값 + **민첩**(주 요인) + **이능**(부 요인)
   이 구조를 공격뿐 아니라 방어(부여자 기준)·힐에도 동일하게 적용해, 방어/힐도 공격처럼
   스탯에 따라 배율이 붙는 크리티컬을 갖게 되었습니다.
6. **공격유도(어그로) 지속 시스템 개편**
   - 더 이상 "다음 라운드가 되면" 자동으로 풀리지 않습니다. 라운드 경계와 무관하게,
     **강제된 적 팀이 실제로 공격을 실행할 때까지** 계속 유지됩니다.
   - 같은 대상에게 공격유도를 여러 번 사용하면 강제 횟수가 **누적**됩니다
     ("다음 공격 N회가 강제됩니다").
   - 안내 문구는 사용 시점뿐 아니라, 강제 대상 팀의 턴이 실제로 돌아올 때
     **그 턴의 개시 문구(Round/선공·후공)보다 먼저** 다시 한번 표시됩니다.
   - 강제 대상이 사망/도주해 무효가 되면 자동으로 해제됩니다.
7. **로그 문구 정리** — "피해 보류" + "판정 대기 중" 두 줄을
   `"{대상} 판정 대기중 (피격자의 행동 대응 후 피해값이 정산됩니다)"` 한 줄로 통합했습니다.

## 이전 패치 2 (밸런스 재설계 + 버그 수정)

**핵심 설계 철학 (고정)**
- 정신 = 다이스 **최소치(안정성)** — 재굴림 기준치(정신 × 3) 이하로 나온 다이스는 한 번 다시 굴립니다.
- 이능 = 다이스 **최대치/면수(폭발력)**
- 공격/방어 = 각 행동의 **직업 특화 보조치**
- 민첩/행운 = **크리티컬** 확률·배율 담당

**반영 사항**
1. **공격 수치 즉시 표시** — 공격을 선언하면 방어/HP 정산과 무관하게 "공격 수치 N"이 운영진 로그와
   러너 공유 로그 모두에 즉시 표시됩니다. 실제 HP 차감(피해량)은 기존처럼 대상이 반응한 뒤 정산됩니다.
2. **방어 계수 상향** — 능동 방어 스탯 배율을 대폭 올렸습니다 (15).
4. **공격유도 대상 선택** — 탱커가 공격유도를 쓸 때 대상을 선택할 수 있습니다. 본인을 지정하면
   어그로와 동시에 능동 방어도 함께 부여됩니다.
6. **힐러의 "후공 페이즈" 행동** — 힐러는 상대 턴이라고 아무 때나 행동 가능한 게 아니라, 정확히
   "이번 라운드의 후공 페이즈"가 되었을 때만 자기 팀 턴이 아니어도 행동할 수 있습니다. (선공팀
   힐러가 행동을 미뤄두면, 상대의 후공 페이즈 중에 반응하듯 사용할 수 있습니다)
7. **힐 회복량 대폭 상향**
8. **딜러 크리티컬** — 확률은 높이고 배율은 낮췄습니다 (변동성 감소, 발생 빈도 증가).
9. **탱커/힐러 크리티컬** — 확률과 배율(효과) 모두 높였습니다.
10. **[버그 수정] 탱커가 부여한 방어의 크리티컬 판정** — 탱커가 아군에게 '방어'를 부여했는데
    "탱커가 아니므로 크리티컬이 발생하지 않는다"고 나오던 문제를 수정했습니다. 이제 방어 총합은
    **"대상 본인의 수동 방어" + "방어를 부여한 탱커의 능동 방어"**로 계산되며, 크리티컬 여부도
    부여자(탱커)의 스탯/역할 기준으로 판정됩니다.
11. **정신 스탯 재굴림 방식으로 변경** — 다이스 값을 정신 스탯으로 그냥 끌어올리는 대신, 재굴림
    기준치(정신 × 3) 이하로 나온 다이스만 한 번 다시 굴리는 방식으로 바뀌었습니다.
12. **수식 수치 반영 및 전반적 재조정** — 공격 크리티컬 배율(기본 1.2, 민첩 가중치 0, 이능 가중치
    0.03), 방어/힐 다이스 개수 2개, 능동 방어 스탯 배율 15를 반영했고, 이에 맞춰 전체적인 수치를
    다시 조정했습니다 (예: 크리티컬 확률이 지나치게 높게 나오는 조합은 완화).
- **"크리티컬!" 문구 통일** — 로그에서 "치명타"/"치명적" 대신 모두 "크리티컬!"로 표시됩니다.
- **캐릭터 스탯 툴팁** — 전투 화면 각 캐릭터 이름 옆 **ⓘ** 아이콘에 마우스를 올리면 해당 캐릭터의
  전체 스탯과 총합을 바로 확인할 수 있습니다.

## 이전 패치 1 (밸런스 재설계 + 버그 수정)

- **탱커 행동 재정의** — "본인방어/타인방어" 대신 아래 3가지로 분리되었습니다.
  - **공격** : 탱커도 이제 공격할 수 있습니다.
  - **방어** : 본인 또는 아군 1명(택1)에게 능동 방어를 부여합니다. 어그로 효과는 없습니다.
  - **공격유도** : 자기 자신에게 어그로를 걸어 상대의 다음 공격을 강제로 자신에게 유도합니다.
    방어 효과는 없습니다.
- **어그로 재정의** — 더 이상 숫자(수치)로 관리하지 않습니다. 공격유도를 사용하면 그 즉시
  상대의 다음 공격이 반드시 그 탱커를 향하도록 강제되며, 전투 화면에는 "🎯 어그로" 뱃지로
  표시됩니다.
- **공통 기본 다이스 공식 통일** — 공격/방어/힐 모두 "정신 = 다이스 눈금의 최저치,
  이능 = 다이스 눈금의 최대치(면수)"라는 동일한 기본 다이스를 사용합니다. 공격력/방어력은
  이 기본 다이스에 더해지는 보조치이며, 힐은 별도의 곱연산 보정 없이 기본 다이스를 그대로
  사용합니다 (기존에 힐러의 정신 스탯이 이중으로 반영되어 과도하게 강했던 문제 수정).
- **힐러 행동 제약 완화** — 공격이 먼저 있어야 한다는 조건이 사라졌고, 힐러는 라운드당 1회
  라는 제한만 지킨다면 자신의 팀 턴이 아니어도(상대 턴 중이라도) 언제든 행동할 수 있습니다.
- **딜러 회피 추가** — 딜러는 "회피"를 선언할 수 있으며, 행운·민첩 스탯을 기반으로 다음
  피격을 완전히 무효화(피해 0)할 확률을 얻습니다. 회피에 실패하면 무방비 상태로 처리됩니다.
- **치명타 확률 상승 / 배율 하향** — 각 치명타 발생 확률을 전반적으로 높이고, 치명타 피해
  배율은 낮춰 변동성은 줄이고 발생 빈도는 늘렸습니다.
- **피해 지연 정산** — 상대가 공격해도 즉시 HP가 깎이지 않습니다. 아직 이번 라운드에 행동하지
  않은 대상을 공격하면 "피해 보류" 상태가 되고, 대상이 자신의 턴에 방어/회피/힐 등으로
  대응한 뒤 그 결과를 반영해 최종 피해가 한꺼번에 정산됩니다. (이미 이번 라운드 행동을 마친
  대상을 공격하면 예전처럼 즉시 정산됩니다) 전투 화면에는 대기 중인 공격 건수가 표시됩니다.
- **다운 상태 사망 확정 시점 변경** — 다운된 캐릭터 본인이 행동을 마쳤다고 바로 사망 확정되지
  않습니다. **그 캐릭터가 속한 팀 전체가 이번 라운드 행동을 마쳐야** 비로소 생사가 확정되므로,
  같은 팀 힐러가 나중에라도 회복시키면 살아남을 수 있습니다.

### 역할별 최종 행동 목록
| 역할 | 사용 가능한 행동 |
|---|---|
| 탱커 | 공격, 방어(본인/아군 택1), 공격유도, 시간초과, 도주 |
| 딜러 | 공격, 본인방어, 회피, 시간초과, 도주 |
| 힐러 | 공격, 본인방어, 힐(라운드 내 언제든 1회), 시간초과, 도주 |

## 이전 업데이트 반영 사항

1. **팀 편성 드롭다운** — 팀 편성 화면의 A/B/C 칸이 데이터베이스에 등록된 이름을 보여주는
   드롭다운(클릭 선택)으로 바뀌었습니다. 직접 타이핑할 필요가 없습니다.
2. **스탯 최대치** — 공격·방어는 최대 3, 나머지(체력/이능/정신/민첩/행운)는 최대 5로 제한되며,
   초과 입력 시 자동으로 최대치로 조정됩니다. 편집 화면에 **스탯 총합**이 실시간으로 표시됩니다.
3. **이중 전투 로그** — 전투 화면 가운데에 로그가 두 단으로 나뉩니다.
   - 위: **🛠 운영진 로그** — 다이스 값, 스탯 배율, 확률, "치명타!" 등 모든 계산 과정 노출
   - 아래: **📋 러너 공유 로그** — 결과값(피해량/회복량/HP 변화)만 간단히 표시
   각 로그마다 **복사** 버튼이 있어 그대로 붙여넣을 수 있습니다.
4. **오류 메시지 복사** — 규칙 위반 등 오류 팝업에도 **복사** 버튼이 있어 그대로 공유할 수 있습니다.
5. **행동 취소(되돌리기)** — 전투 화면 상단의 **↩ 행동 취소** 버튼으로 가장 최근 행동(공격/방어/힐/
   시간초과/도주/턴 전환)을 취소하고 다시 행동할 수 있습니다. 여러 번 눌러 여러 단계 되돌리기도 가능합니다.
6. **본인방어 / 타인방어** — "방어"가 두 가지로 나뉩니다. 모든 역할은 자기 자신만 방어할 수 있는
   **본인방어**를 사용할 수 있고, **탱커만** 아군을 대신 지키는 **타인방어**를 사용할 수 있습니다.
7. **HP 범위 조정** — 체력 스탯(1~5)에 따라 최대 HP가 대략 150 ~ 250 사이가 되도록 공식을 재조정했습니다
   (`HP = 125 + 체력 × 25`).
8. **전투 규칙 정합성 개선**
   - 이번 라운드에 아직 "방어"(본인방어/타인방어)를 선언하지 않은 대상은 **무방비(수동 방어)**
     상태로 처리되어 방어 다이스를 굴리지 않고, **방어 치명타도 발생하지 않습니다.**
     (방어를 선언한 뒤에만 능동 방어 굴림 + 방어 치명타 가능)
   - 로그 표기를 "최종 피해" → **"피해량"** 으로 변경했습니다.
   - 한 라운드의 모든 인원이 행동을 마치면, 다음 라운드로 넘어가기 직전에
     **[Round N 요약]** 으로 전원의 "시작 체력 → 종료 체력"을 자동으로 로그에 남깁니다.
9. **라운드 타이머** — 전투 화면 상단에 라운드당 5분 카운트다운 시계가 표시됩니다.
   제한시간이 지나면 알림이 뜨며, 남은 인원은 "시간 초과" 버튼으로 처리할 수 있습니다.
   (제한시간은 "⚙ 전투 수식 설정"에서 조정 가능)
10. **역할별 행동 체계 확장**
    - 딜러 : 공격, 본인방어
    - 탱커(방어자) : 본인방어, 타인방어
    - 힐러 : 공격, 본인방어, 힐
    - 전원 공통 : **시간 초과**, **도주** (도주하면 해당 캐릭터는 이후 전투에 참여하지 않습니다)
11. **어그로 뱃지** — 타인방어를 사용한 탱커의 이름 옆에 🎯 숫자로 어그로 수치가 표시됩니다.
    (타인방어 1회당 +30, 매 라운드 절반씩 감소)
12. **로그 UI/UX 개선** — 라운드 구분선, 행동/치명타/피해/회복/HP 변화에 색상과 아이콘을 입혀
    한눈에 흐름을 파악할 수 있도록 개선했습니다.
13. **선공 자동 결정** — 더 이상 운영자가 직접 선공을 고르지 않습니다. 전투 시작 시
    양 팀의 **민첩 합산**을 비교해 자동으로 선공을 정하고, 화면에 근거를 안내합니다.
    동점이면 각 팀 대표로 1d100을 굴려 더 높은 쪽이 선공입니다.
14. **캐릭터 목록 포지션순 정렬** — 데이터베이스 화면의 등록된 캐릭터 목록이
    탱커 → 딜러 → 힐러 순으로 정렬됩니다.
15. **전투 수식 열람 및 수정** — 데이터베이스 화면 우측 상단의
    **"⚙ 전투 수식 설정 (운영진 전용)"** 버튼을 누르면 현재 적용된 모든 전투 수식(다이스 면수,
    스탯 배율, 치명타 확률/배율, HP 공식, 어그로/타이머 수치 등)을 설명과 함께 확인하고
    직접 값을 수정할 수 있습니다. 저장하면 `formulas.json`에 기록되어 다음 실행 시에도 유지됩니다.
16. **포지션 치명타 제한** — 치명타는 그 역할이 "본인 포지션다운 행동"을 했을 때만 발생합니다.
    - 공격 치명타 : **딜러**가 공격할 때만 (힐러가 공격해도 치명타 없음)
    - 방어 치명타 : **탱커**가 능동 방어할 때만 (딜러/힐러의 본인방어는 치명타 없음)
    - 회복 치명타 : **힐러**가 힐할 때만
    운영진 로그에는 포지션이 맞지 않아 치명타가 발생하지 않았다는 안내도 함께 표시됩니다.
17. **다운(빈사) 상태 도입** — 아직 이번 라운드 자신의 턴이 오지 않은 캐릭터가 공격으로 HP 0이 되어도
    즉시 사망 처리하지 않고 **다운** 상태가 됩니다. 다운된 캐릭터는 team 전멸 판정에서 "생존"으로
    간주되어 전투가 곧바로 끝나지 않으며, 자신의 턴이 오면 평소처럼 행동(방어/힐/공격 등)할 수
    있는 마지막 기회를 가집니다.
    - 그 사이 아군이 힐로 0 초과까지 회복시키면 다운에서 벗어나 정상적으로 계속 싸울 수 있습니다.
    - 다운된 캐릭터 스스로도 힐러라면 자가 치유로 살아남을 수 있습니다.
    - 마지막 행동을 마쳤는데도 회복되지 못했다면 그 시점에 완전히 사망 처리됩니다.
    - 이미 이번 라운드 행동을 마친 뒤(즉, 자신의 턴이 지난 뒤) 공격받아 HP 0이 되면 다시 살아날
      기회가 없으므로 곧바로 사망 처리됩니다.
    - 전투 화면에는 다운 상태가 주황색 "☠ 빈사" 표시와 함께 HP 게이지에 나타납니다.

## 사용 순서

1. **캐릭터 데이터베이스 화면**
   - 왼쪽 텍스트창에 형식대로 붙여넣고 "일괄 등록"을 누릅니다. (`역할` 줄은 선택 사항)
   - 스탯이 최대치를 넘으면 자동으로 조정되며, 조정 내역이 안내됩니다.
   - 오른쪽 목록(포지션순)에서 캐릭터를 선택해 수정/삭제할 수 있고, 스탯 총합이 함께 표시됩니다.
   - 필요하면 "⚙ 전투 수식 설정"에서 전투 계산식을 직접 조정할 수 있습니다.

2. **팀 편성 화면**
   - 1팀/2팀 각 A, B, C 드롭다운에서 캐릭터를 선택합니다.
   - "전투 시작"을 누르면 민첩 합산으로 선공 팀이 자동 결정되고, 그 근거가 안내됩니다.

3. **전투 화면**
   - 각 캐릭터 카드의 버튼(공격/본인방어/타인방어/힐/시간 초과/도주)으로 행동합니다.
   - 잘못 눌렀다면 **↩ 행동 취소**로 되돌리고 다시 행동할 수 있습니다.
   - 모든 생존 캐릭터가 행동을 마쳐야 "다음 턴"으로 넘어갈 수 있습니다.
   - 탱커가 타인방어를 선언하면 상대의 다음 공격 1회는 반드시 그 탱커를 대상으로 해야 하며,
     어그로 수치가 뱃지로 표시됩니다.
   - 힐러는 같은 팀에서 공격이 1회 이상 발생한 뒤에만 힐을 사용할 수 있습니다.
   - 라운드가 끝나면 로그에 전원의 시작/종료 체력 요약이 자동으로 남습니다.
   - 한 팀이 전멸(사망+도주)하면 자동으로 승리 팀 팝업이 표시됩니다.

## 전투 수식 커스터마이징

`config.py`에 모든 계산식과 기본값이 정리되어 있고, 프로그램 실행 중
"⚙ 전투 수식 설정" 화면에서도 동일한 항목을 즉시 수정할 수 있습니다.

## exe로 빌드하기 (Windows)

```bash
pip install pyinstaller
pyinstaller --onefile --noconsole --name PvP전투관리 main.py
```

`dist/PvP전투관리.exe` 가 생성됩니다. `characters.json`, `formulas.json`은 exe와 같은 폴더에
자동으로 생성/저장되므로, 쓰기 권한이 있는 폴더(바탕화면, 문서 폴더 등)에서 실행하세요.
